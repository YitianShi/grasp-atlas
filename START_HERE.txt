阅读论文
--------
双击根目录 index.html，搜索论文后点击「打开本地 PDF」。论文标题也优先打开本地全文。
本地 PDF 可离线阅读。「在线论文」进入该文出版页或预印本页；「在线 PDF」打开已验证的在线版本。
没有取得全文的条目会明确显示未下载或暂不可用，不会把目录、摘要或错误论文当成全文。

永久删除
--------
双击 Start_Grasp_Atlas.cmd，在回收站找到论文，点击“永久删除”，核对标题后确认。
若已运行旧版本服务，请先关闭旧启动窗口，再双击启动器。
确认后清理该论文的目录、摘要、链接、本地 PDF、候选文件、下载残片、下载记录、历史筛选项及备份中的相关记录，并重建页面。
永久删除不能撤销，“恢复全部”也不能找回。普通“删除”仍可在回收站恢复。
直接双击 index.html 时会提示通过启动器打开。下载运行期间不可永久删除；其他论文共用的 PDF 会保留。

下载 / 继续 / 重试
-----------------
双击 Start_Grasp_Atlas.cmd，在打开的本机网页中点击「下载 / 重试全部」。
网页显示进度并自动更新全文入口。启动窗口关闭后网页服务会停止，已开始的下载可继续。
或者双击 Download_All_Papers.cmd，直接启动完整下载。
需要 Python 3.10 或更新版本；下载启动器首次运行会创建专用环境并安装 pypdf。
已下载且 SHA-256 正确的论文会跳过；中断的文件保留，可再次运行继续。
同一个论文库有进程锁，避免同时启动多个下载器。

文件位置
--------
GraspAtlas_Library/papers/年份/会议或期刊/：已通过全文标题核验的 PDF。
GraspAtlas_Library/download_index.csv：全部记录、状态、中文原因、文件及下载来源。
GraspAtlas_Library/not_downloaded.csv：未取得全文或仍需核验的记录。
GraspAtlas_Library/needs_review/：不通过检查的候选文件，绝不作为正文打开。
GraspAtlas_Library/download_state.json：断点与来源记录，请保留。
library.js：网页读取的全文索引，下载器自动更新。

双击 index.html 阅读时，下载后点击「刷新全文状态」或刷新浏览器。
请把 index.html、library.js、GraspAtlas_Library 和 editable-site 一起保留或移动。
已下载内容实际存在本机磁盘，不嵌入 index.html。

English
-------
Open index.html and select “Open local PDF”. Titles prefer verified local files.
Run Start_Grasp_Atlas.cmd for the local web app and its “Download / retry all” button,
or run Download_All_Papers.cmd directly. Downloads resume and verified files are skipped.
Keep library.js and GraspAtlas_Library beside index.html. Public full text may be unavailable
for some records; their online source and explicit download status remain accessible.
